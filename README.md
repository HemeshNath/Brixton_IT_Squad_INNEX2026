1. Project Description
Check Scam is an AI-powered mobile security application designed to help users identify potentially fraudulent messages and phishing attempts. It aims to improve digital safety by providing automated screening of incoming message notifications from supported communication platforms.
The application combines notification monitoring, privacy-conscious data processing, external threat intelligence, and AI-based risk assessment to evaluate potential security threats. It provides users with timely warnings and risk information, helping them recognize suspicious messages before interacting with potentially harmful content.
Developed with Flutter and native Android functionality using Kotlin, Check Scam focuses on making digital communication safer, more accessible, and user-friendly. It is particularly intended to address the growing problem of online scams in Nepal, including fraudulent messages written in Nepali, Romanized Nepali, and English.

2. Problem Statement and Project Objectives
2.1 Problem Statement
Digital scams and phishing attacks are increasing alongside the use of smartphones, online banking, digital wallets, and messaging platforms. Fraudsters use deceptive messages, impersonation, fake offers, and malicious links to trick people into sharing sensitive information or performing unsafe actions.
Many users, particularly those with limited cybersecurity awareness, struggle to distinguish legitimate messages from fraudulent ones. Manual verification also requires additional effort and may happen only after a user has already interacted with suspicious content.
There is a need for an accessible and proactive solution that helps users identify potential scams, assess their risks, and make safer decisions while using digital communication platforms.
2.2 General Objective
To develop an AI-powered mobile security application that helps users detect potentially fraudulent messages and phishing attempts through automated screening and intelligent risk assessment.
2.3 Specific Objectives
1.	To provide automated screening of incoming message notifications from supported messaging platforms.
2.	To identify suspicious URLs and potential threat indicators within available message content.
3.	To protect user privacy through Personally Identifiable Information (PII) removal.
4.	To utilize external threat intelligence for identifying potentially malicious indicators.
5.	To apply AI-based analysis for evaluating potential security risks.
6.	To provide clear risk scores, classifications, and security warnings.
7.	To improve awareness of digital scams and encourage safer online communication

3. Proposed Solution and Key Features
3.1 Proposed Solution
Check Scam proposes an AI-powered mobile security solution that helps users identify potential scams and phishing attempts through both automated notification screening and manual security checks. Users can either allow the application to screen supported incoming message notifications automatically or manually submit suspicious messages and links for analysis.
By combining privacy-conscious data processing, external threat intelligence, and AI-based risk assessment, the application provides security evaluations and timely warnings to help users make safer decisions before interacting with potentially harmful content.
3.2 Key Features
1. Automated Notification Screening
Screens incoming message notifications from supported platforms, including SMS, WhatsApp, Messenger, and Viber, to identify potential security threats.
2. Manual Message Checking
Allows users to copy and paste suspicious messages into the application for security analysis.
3. Manual URL Checking
Enables users to submit suspicious website links directly for threat analysis without needing to receive them as notifications.
4. Message and URL Analysis
Extracts available message content, URLs, and relevant threat indicators for security assessment.
5. PII Detection and Removal
Identifies and removes personally identifiable information from extracted content to reduce unnecessary exposure of sensitive user data.
6. Threat Intelligence Integration
Uses AlienVault Open Threat Exchange (OTX) to check extracted URLs and supported indicators against available cybersecurity threat intelligence.
7. AI-Based Risk Assessment
Integrates Mira V1 (Sagea-AI) to evaluate threat-intelligence results and generate security assessments.
8. Risk Scoring and Classification
Provides risk scores and security classifications to communicate the potential severity of detected threats.
9. Real-Time Security Alerts
Notifies users when an incoming message notification is identified as potentially fraudulent, helping them take precautions before interacting with it.
10. User-Friendly Mobile Interface
Provides an accessible interface for manually checking messages and URLs, viewing security alerts, and understanding potential digital threats.
